Automatización del Flujo de Proyectos en Jira

Una automatización en Jira que, con un solo clic, crea una lista estándar de tareas para proyectos de landing pages.

Sobre el
proyecto

Diseñé un flujo de trabajo en Jira que crea automáticamente las tareas para proyectos de landing pages, desde la planificación hasta la publicación, reduciendo la configuración manual.

Servicios

Diseño de flujos de trabajo,
Automatización en Jira

Detalles del proyecto

Este proyecto comienza con un Epic para una nueva landing page. Un disparador manual inicia la automatización en Jira y crea siete elementos de trabajo hijos:

  • Descubrimiento: Recopilar requisitos
  • Planificación: Definir el alcance y el plan del proyecto
  • Diseño: Crear el diseño del sitio web
  • Aprobación: Aprobar el diseño con el cliente
  • Desarrollo: Desarrollar el sitio web aprobado
  • QA: Realizar pruebas de calidad
  • Lanzamiento: Publicar el sitio web

Cada elemento de trabajo incluye una descripción, checklist, etiquetas, el Epic padre y fechas de entrega en días hábiles. Usé el smart value {{triggerIssue.summary}} para que el nombre del proyecto se agregue automáticamente a cada tarea.

El objetivo era crear un proceso de configuración claro y repetible, reduciendo el trabajo manual en Jira.

Lo que hice

  • Identifiqué el trabajo repetitivo en la configuración de proyectos.
  • Definí las etapas de los proyectos de landing pages.
  • Escribí nombres de tareas claros con etiquetas por etapa.
  • Configuré un disparador manual en Jira.
  • Configuré las acciones para crear las tareas del proyecto.
  • Usé un smart value de Jira para agregar el nombre del proyecto a cada tarea.

Resultado: Reduje en un 21% el tiempo de configuración de proyectos, ahorrando 3 horas de un proceso de 14 horas al automatizar la creación de 7 tareas del proyecto.
